# GUVEL Operational — Phase 2.0.H.11
## Quality & Downtime KPI Card Height Refinement

### Scope
This phase makes only the outer KPI cards in Quality and Downtime shorter. The typography, icons, KPI values, labels, comparison text, threshold behavior, and internal visual elements are intentionally preserved.

### Change
- Quality KPI cards: fixed outer height 104px.
- Downtime KPI cards: fixed outer height 104px.
- `box-sizing: border-box` keeps the dimensions predictable.
- No changes to KPI content sizing or threshold logic.
- Responsive layout preserved.

### Explicitly unchanged
- KPI formulas and threshold evaluation.
- Threshold LED/pulse behavior.
- KPI typography and icon sizes.
- General KPI visual language.
